# ── The order the board deals a run in ──────────────────────────────
# One picture per line, as <study folder>/<file name without its
# extension> — the same shape as the skip list, minus the extension,
# because the board deals a thumb and a thumb is named for its stem.
#
# Lines are grouped under a run: "# open" is the opening set, then
# "# digital", "# app", "# creative", "# interiors", "# staples". A
# picture named here is dealt in the order it appears; everything else
# in that run follows, in the order the deal gives it. So a partial
# list is enough — name the three that should lead and leave the rest.
#
# A picture named under a run is dealt there even if the sweep cut it
# (a cut plate is thumbed for the preview and marked x): that is how a
# study shows on every line it sits on. "# off" holds a picture off the
# field without cutting it; it still opens in its study's column.
#
# Ordered by hand on lab/board-order.html (Copy order), read by
# scripts/lib/assemble-board.py; `npm run board:page` re-deals with it,
# no thumbs needed. Lines starting with # are notes.
