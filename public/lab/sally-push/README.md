# sally-push

The editorial pass on his Sally Beauty concepts (2 Oct 2026): Satoshi in
place of Founders Grotesk, white paper in place of the Natural-scale
panels, stories told in order. Hand-made, unlike `../sally-system/`,
which the import script rewrites.

- `index.html`: before and after, live, side by side
- `the-color-issue.html`: The Edit (concept 10) pushed, desktop and phone
- `the-gloss.html`: the editorial email pushed
- `the-sale.html`: the color-blocked sale email pushed
- `push.css`: tokens, type and both layouts

Pictures come from `../sally-system/assets/`. Satoshi is the site's own
`/fonts/Satoshi-Variable.woff2`.
